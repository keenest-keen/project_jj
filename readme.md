# PROJECT_JJ

Однажды я всё-таки реализовал идею перейти с ЖЖ на что-то поудобнее. Перетащив при этом весь багаж накопившихся там постов.
Осенью 2026-го я сделал это, разработав (не без помощи ИИ) соответствующий софт, и выложил первую версию проекта.

## Составляющие

- **Extractor** - модуль экстракции данных из html-файлов, выгруженных из **LJSM**. Результат работы - .json-файлы со всей информацией о постах (заголовок, дата публикации, тело поста, тэги и т.д.).

- **Generator** - модуль генерации по json-файлам готового блога в html-формате (технология SSG): начиная с `index.html` и всё-всё остальное.

- **Poster** - WYCIWYG-редактор для постов. С поиском и превью.

- **mood_extractor** - утилитка для выкачивания из ЖЖ картинок-смайликов с настроениями.

## Использование

В папке с каждым из упомянутых модулей лежит свой readme-файл с детальным описанием возможностей и механизмов работы.

В корне проекта лежат 4 скрипта, которые сначала спрашивают нужную информацию, а затем запускают что надо:

- `do_extract.sh` - процедура экстракции;

- `do_generate_blog.sh` - генерация блога;

- `do_localhost.sh` - простейший веб-сервер для локального просмотра результата;

- `do_poster.sh` - просмотр/редактирование постов.
